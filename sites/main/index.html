Om verktygen

Denna samling verktyg hjälper dig att analysera träningsdata och förstå din prestationsförmåga. Alla verktyg använder vetenskapligt baserade modeller för att ge dig insikter i din träning.

  • Critical Power Model: Analyserar cykelprestation baserat på två testpunkter
  • Critical Speed Model: Förutsäger löptider baserat på testresultat
  • FIT File Analysis: Detaljerad analys av träningsfiler med TSS-beräkningar
